## Conteúdo

- `ML/`: página inspirada na promoção de abril do Mercado Livre
- `Menu/`: menu de navegação
- `PaginadeVendas/`: página de vendas com vídeo
- `contagemRegressiva/`: contagem regressiva de 15 minutos em JavaScript
- `listas_complexas/`: listas complexas em HTML

## Como rodar

Cada pasta é um projeto independente. Basta abrir o `index.html` da pasta desejada no navegador.
